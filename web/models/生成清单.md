# 模型生成清单（网页版 Tripo）

生成后下载 **GLB** 格式，按下面的**文件名**存到这个文件夹（`v2/models/`）。放进来我就能接进游戏。

## 通用设置

- **格式**：GLB，带贴图
- **面数**：人物 2–3 万面，车辆 3–5 万面。有"低模 / 智能减面 / 游戏用"之类选项就选上
- **人物姿势**：描述里都写了 A-pose（双臂微微张开站立），这样绑骨骼最稳
- **绑骨骼**：人物全部要绑（Rig / 自动绑定）。车辆不用
- **动作**：如果网页上能给绑好的人物套预设动作，**阿凯**请导出这几个，分别存成单独文件：站立 `kai@idle.glb`、走 `kai@walk.glb`、跑 `kai@run.glb`。其他人物有余力再做 idle 和 walk
- **省积分**：开始前先看一眼网页上每次生成和每次绑骨骼各扣多少。按下面的顺序做，积分不够了就停，前面的最重要
- 描述用英文效果更稳，直接复制 **Prompt** 那一行即可。都是原创角色，没有真人和品牌
