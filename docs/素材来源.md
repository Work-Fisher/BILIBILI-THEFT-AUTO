## Windows 可选神经渲染

Windows 下载默认直接显示游戏原画。已持有兼容后端并有权使用的玩家，可关闭游戏，把 video2dlssnr.exe、nvngx_dlss.dll、nvngx_dlssnr.dll 和 nvngx.dll_dlssnr.dll 放到游戏目录的 resources/neural，再启动游戏。F8 切换原画和神经渲染，F7 切换行车和逐帧模式。兼容性取决于 GPU、驱动与后端版本。本项目的 Windows 适配基于社区后端 v1.4.1。[后端项目](https://github.com/DaniilSokolyuk/video2dlssnr/tree/v1.4.1) · [NVIDIA 组件条款](https://github.com/NVIDIA/DLSS/blob/main/LICENSE.txt)
